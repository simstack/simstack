simstack.persistence.criteria module¶

Backend-neutral repository criteria.

The domain package describes intent (field, comparison, value); concrete adapters decide how to express that intent in their storage query language. No MongoDB operators or driver types are exposed here.

Module contents¶

Persistence ports and backend-neutral query criteria.

This package contains contracts only. MongoDB adapters and database clients belong to simstack-server and are intentionally absent from simstack.
