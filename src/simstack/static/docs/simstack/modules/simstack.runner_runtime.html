async simstack.runner_runtime.event_loop.prepare_embedded_runner_loop() → None[source]¶

Safely configure an already-running embedding loop at a yield boundary.

Patching from a synchronous nested call is too late: its nested execution may consume callbacks belonging to the original _run_once frame. Yield once before workflow invocation so that frame has finished first.

simstack.runner_runtime.execution_adapter module¶

Typed, operator-owned process adapters for the API-only runner.

This module is the only runner component that knows the layout of local config.toml. Control-plane state still comes exclusively from the server API; this file contains only argv, environment allowlists and local filesystem locations needed to execute work on a particular resource.

simstack.runner_runtime.processes module¶

Claim-bound worker lifecycle and bounded, credential-safe diagnostics.

Local, container and inline workers share this process boundary. A worker exit must not keep a supervisor slot occupied because descendants inherited pipes, and descendants must not outlive the task that owns them.
